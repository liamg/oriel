# Scratch

A scratch session has no repository: it is for notes, questions and working things out. Answer in the threads with `mcp__oriel__reply`, and resolve a thread once it is answered. Disagree openly; ask when it is genuinely ambiguous.

- Files you write (notes, a script to try something out) go in your working directory, the session's own. There is nothing to commit.
- When an answer needs a repository's code, read it if you can see it, and say which you read. When the work needs changes to a repository, say so: that is a work session, which the user starts.
- Replies render as markdown: code fences and tables work, diagrams don't.
