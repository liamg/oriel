Across projects, the merge order and "raise all" live in Ship (18).
The sidebar
Projects at a glance. Each header carries branch, ahead, changes, PR and a CI dot, so api failing CI shows while you work in admin-ui.
Per-project panels: Explorer, Search, Git, Pull request, Tests. Each project reopens its last panel.
Session-wide, below the divider: Requests, Ship (with 2+ projects to ship), Settings. ⌘K stays global.
Degrades cleanly: one project or a directory is a labelled sidebar with no header; Pull request only with a remote.
Tabs across projects
One tab strip for the session. A proto from api sits beside code in admin-ui.
Each tab leads with a square in its project's colour, the header's colour; its tooltip names the project. With one project, tabs keep their file icon.
The breadcrumb starts with the project: api › proto › usage.proto.
Opening a file from another project doesn't switch the sidebar's open project.
Pull request and Ship
Pull request in the dock is a compact checklist: committed → up to date → pushed → PR → checks.
Raise PR (or Edit PR) opens a full-width main tab: title and body, reviewers, cross-linked PRs, and the "before this ships" gates.
Ship is 18's full page: every project's checklist side by side with the merge order.
Costs: ~225px in the wide form; two lines per folded project, scrolling past ~8 with the session's entries pinned.
Keys
⌃1–⌃9 open a project: it expands, the open one folds, its last panel reopens.
In the sidebar: j k move over headers and entries, ⏎ expands a header or opens an entry.
⌘⇧E ⌘⇧F ⌘⇧G ⌘⇧T open that panel for the open project; ⌘⇧R stays session-wide.
Clicking the open entry hides the dock. « / » toggles wide and narrow, remembered per window.
