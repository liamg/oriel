Session tokens are minted

Once the user exists, the callback hands off to session.Mint. It issues two tokens with very different lifetimes: a short access token the API checks on every request, and a long refresh token that only the refresh endpoint ever reads.

45 if err != nil { return Pair{}, err }

The refresh token is a row, not a JWT: the family lets step 7 revoke every descendant when a reused token shows up.

The dashboard never sees the refresh token's value. It only learns when the access token will expire, so it can schedule a refresh before the user notices:
