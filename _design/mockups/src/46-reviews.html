What the page is
Every PR waiting on your review, from every review source: GitHub built in, GitLab and Azure DevOps as plugins.
Grouped Waiting on you (oldest ask first) then In progress. Filter to me or my teams.
Laid out as the Tickets and Jobs pages: list left, selected PR right.
Start and continue
Start review… opens the launcher on Review PR with the PR filled in. The session is the existing review kind: read-only worktree at the PR's head, AI review as it starts.
Continue review… when a session's PR is this one: session.open, resuming it if stopped.
Open in GitHub / GitLab / Azure: the PR's web page.
The badge
The sidebar's Reviews pill is how many are new or re-requested and have no session. Violet, so it doesn't read as Requests' amber.
Asked again every 5 minutes while Oriel is open, on focus after 1 minute, and on r.
A new ask is a notice: "mkhan asked you to review api#812".
Keys
:Reviews ⌘⇧V, the sidebar, the start view. In the page: j k, ↵ start or continue, o open in the browser, r refresh, / filter, t to me / teams.
The omnibox's PRs gain review requests; the assistant's review_requests reads every source.
