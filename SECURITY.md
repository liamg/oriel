# Security

Please report security problems privately, not in a public issue.

Use GitHub's private vulnerability reporting: on [liamg/oriel](https://github.com/liamg/oriel), open the
**Security** tab and choose **Report a vulnerability**
([direct link](https://github.com/liamg/oriel/security/advisories/new)).

Include the Oriel version, your OS and architecture, what an attacker can do, and the steps to reproduce it. Once a
fix is released, the advisory is published with credit to you, unless you'd rather not be named.

Oriel is pre-1.0: only the latest release gets security fixes.

Things that are in scope include the updater (release signing and verification), the sandbox, plugin permissions,
and anything that lets a repository, a plugin or a remote service run code or read files it shouldn't.
