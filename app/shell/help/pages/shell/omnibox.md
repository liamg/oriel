# The omnibox

`⌘K` searches everything at once: sessions, commands, files and symbols, one ranked list with a preview of
what's highlighted.

- Type to match fuzzily: the letters in order, with runs, word starts and path separators counting for more.
- Start with `@` for files, `#` for symbols, `>` for commands; `⇥` steps through the scopes.
- `↵` opens the highlighted result, and `esc` closes.
- A session that needs you comes first.
